# CMCD with Orange CDN and Hydrolix

Send CMCD data from Player to Orange CDN and query it through Hydrolix and Bitmovin Observability

Watch Bitmovin's Player attach standardised CMCD (Common Media Client Data, CTA-5004) telemetry to every manifest and segment request. Streams are delivered live from Orange CDN and CMCD-enriched request logs are streamed into Hydrolix, where they can be joined with Bitmovin Observability data through a shared session ID.
